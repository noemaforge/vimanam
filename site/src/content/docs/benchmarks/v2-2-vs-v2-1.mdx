Vimanam `2.2.0` replaced external `protoc` with pure-Rust `protox 0.10`, replaced `serde_norway` (wrapping C-ported `unsafe-libyaml-norway`) with `serde-saphyr 2.2` (`#![forbid(unsafe_code)]`), replaced unmaintained `graphql-parser 0.4` with `apollo-parser 0.8`, added `.proto` source comment rendering, and resolved `RUSTSEC-2026-0486`.

All comparisons below use `hyperfine 2.0.0` medians and Q1–Q3 interquartile ranges (raw captures in [`scripts/benchmark-v22-results.json`](https://github.com/noemaforge/vimanam/blob/main/scripts/benchmark-v22-results.json)).

### Git-ref `.proto` diff scaling (measured)

In `v2.1.0`, Git-ref `.proto` diffs extracted every committed `.proto` file in the repository to temporary directories on disk for both refs before invoking `protoc`. In `v2.2.0`, `GitFileResolver` verifies committed `.proto` file modes (rejecting symlinks) and lazily reads only imported blobs in memory:

| Git-ref `.proto` diff benchmark | Committed `.proto` files | v2.1.0 median (IQR) | v2.2.0 median (IQR) | Median speedup | Instructions (2.1 → 2.2) | Exact diff parity |
|---|---:|---:|---:|---:|---:|---|
| **OpenTelemetry Proto** (`d31f7ac~1..d31f7ac`, `trace.proto`) | `11` | `2,164.4 ms` (`2,133–2,173`) | **`798.4 ms`** (`782–808`) | **`2.71×`** | `736.8M -> 321.2M` | Exact (`1` change) |
| **Synthetic repo** (`scripts/benchmark-public.py`, 4 imported) | `200` | `29,545.6 ms` (`28,744–29,615`) | **`966.2 ms`** (`946–990`) | **`30.58×`** | `7,508.7M -> 271.2M` | Exact (`1` change) |

## OpenAPI and GraphQL: v2.2.0 vs v2.1.0 (median, IQR, and RSS)

Pairs whose interquartile ranges (Q1–Q3) overlap are marked as parity rather than speedups or regressions:

| Public specification | v2.1.0 median (IQR / RSS) | v2.2.0 median (IQR / RSS) | IQRs disjoint? | Parity & notable change |
|---|---|---|---|---|
| **Petstore OAS3** (`2.6 KB` JSON) | `7.90 ms` (`7.1–9.7` / `4.0 MB`) | `7.78 ms` (`7.2–8.2` / `4.1 MB`) | No (startup floor) | Byte-identical |
| **Petstore OAS3** (`1.9 KB` YAML) | `8.96 ms` (`7.9–9.8` / `4.2 MB`) | `9.11 ms` (`7.9–9.4` / `5.1 MB`) | No (startup floor) | Byte-identical |
| **OpenAI OpenAPI 3.0** (`1.3 MB` YAML) | **Failed (`exit 1`)** | **`45.33 ms`** (`44.0–46.2` / `23.5 MB`) | Pass vs fail | `serde_norway` rejected `-9223372036854776000` in `seed.minimum`; `serde-saphyr` parses cleanly |
| **Stripe OpenAPI 3.0** (`7.9 MB` JSON) | `113.43 ms` (`111.6–114.5` / `124.2 MB`) | `111.00 ms` (`109.6–111.6` / `124.0 MB`) | No (parity) | Byte-identical (`1,456M` vs `1,454M` instr) |

| **SpaceX Land GraphQL** (`12 KB` SDL) | `11.27 ms` (`9.8–11.9` / `5.3 MB`) | `10.86 ms` (`9.2–12.2` / `5.1 MB`) | No (parity) | Byte-identical |

<Aside type="caution" title="Upgrade regressions and binary size trade-offs">
  - **Binary size**: the `arm64` release binary grew from `7.24 MB` (`v2.1.0`) to `9.28 MB` (`v2.2.0`, `+2.04 MB`) to bundle `protox`, Google well-known descriptors, `apollo-parser`, `serde-saphyr`, and optional Nushell/manpage generators.
  - **Large YAML parse time**: on Stripe `6.3 MB` YAML, `serde-saphyr` is `+13.1 ms` (`+6.8%`) slower by median while reducing peak RSS by `19.8%` and eliminating `unsafe-libyaml-norway` (`#![forbid(unsafe_code)]` lives on `serde-saphyr`, not crate-wide on `vimanam/src/`).
  - **Large GraphQL SDL parse time**: `apollo-parser` adds `+12.1 ms` (`+22.9%`) on GitHub's `1.2 MB` SDL.
</Aside>
