## Measurement environment and methodology

All measurements on these pages come from public open-source specifications (plus three checked-in synthetic multi-file Protobuf specs for zero-memorization LLM evaluation) captured on one Apple Silicon (`macOS 26.7 arm64`) machine.

| Tool / corpus | Version or pinned commit | Role |
|---|---|---|
| Vimanam | `2.3.0` (`f02778f4…`) against `2.2.0` (`ed253315…`) on the v2.3 pages; `2.2.0` against `2.1.0` (`923af877…`) on the v2.2 pages | Release binaries built with `cargo build --release --locked` |
| Timing harness | `hyperfine 2.0.0` | Medians, Q1–Q3 IQRs, min–max, peak RSS, CPU instructions, raw `samples_ms` |
| LLM & BPE | `claude-haiku-5-5` via `claude -p` (serial, zero tools), `tiktoken` (`o200k_base`) | 3 cold trials per cell (fresh prompt-cache nonce each) plus 1 warm replay; deterministic JSON assertions, no LLM judge |
| External baselines | `oasdiff 1.40.0` (v2.3 pages) or `1.39.0` (v2.2 pages), `buf 1.75.0`, `graphql-inspector 7.0.8`, `protoc-gen-doc 1.5.1`, `libprotoc 36.2` | Format-specific diff and doc-generation baselines |
| OpenAI OpenAPI | `498c71d` (`1.3 MB` YAML) · `a01e367..373f26a` (`4.9 MB` JSON) | Standalone render, LLM eval, and `oasdiff` revision diff |
| Stripe OpenAPI | `2f8d147..5237fa0` (`7.9 MB` JSON, `6.3 MB` YAML) | Render latency, LLM eval overflow, and cyclic `$ref` diff probe |
| GitHub GraphQL | `a6de3c1..597478f` (`1.2 MB` SDL, `5.0 MB` Introspection JSON) | Render latency, LLM eval, Git-ref diff, and `graphql-inspector` |
| OpenTelemetry Proto | `40cb2e5..d31f7ac` (`11` `.proto` files) | Pure-Rust `.proto` compile, `buf breaking` Git-ref, `protoc-gen-doc`, and the real-spec LLM follow-up task (`d31f7ac`) |
| Stripe release history (v2.3) | 15 consecutive `openapi/spec3.json` pairs, `a402765` to `bcfd59f` | `diff` timing and accuracy against `oasdiff` |
| GitHub GraphQL history (v2.3) | 8 consecutive `schema.json` commit pairs, `b64979a` to `597478f` | Accuracy against `graphql-inspector`, and SDL against introspection |
| OpenTelemetry Proto releases (v2.3) | 8 consecutive tags, `v1.4.0` to `v1.11.1` | Accuracy against `buf breaking` |
| Synthetic eval protos | [`scripts/eval-fixtures/protos/`](https://github.com/noemaforge/vimanam/tree/main/scripts/eval-fixtures/protos) | Non-memorizable `ledger/v1`, `fleet/v2`, and `vault/v1` RPC tasks |

### Statistical conventions

- **Medians and IQRs over means**: every timing table reports the **median** and **interquartile range (Q1–Q3)** across runs so single scheduling outliers never hide real regressions or exaggerate speedups. Version pairs whose IQRs overlap are reported as parity.
- **Raw data checked into Git**: full `samples_ms` arrays, SHA-256 binary hashes, pinned commit SHAs, and every per-trial LLM assertion check live in:
  - [`scripts/benchmark-public.py`](https://github.com/noemaforge/vimanam/blob/main/scripts/benchmark-public.py) and [`scripts/benchmark-v22-results.json`](https://github.com/noemaforge/vimanam/blob/main/scripts/benchmark-v22-results.json)
  - [`scripts/eval-context-accuracy.py`](https://github.com/noemaforge/vimanam/blob/main/scripts/eval-context-accuracy.py) and [`scripts/eval-context-accuracy-results.json`](https://github.com/noemaforge/vimanam/blob/main/scripts/eval-context-accuracy-results.json)
  - For 2.3.0: [`scripts/benchmark-v23-results.json`](https://github.com/noemaforge/vimanam/blob/main/scripts/benchmark-v23-results.json), [`scripts/eval-context-accuracy-v23-results.json`](https://github.com/noemaforge/vimanam/blob/main/scripts/eval-context-accuracy-v23-results.json), and [`scripts/benchmark-diff-refs-v23-results.json`](https://github.com/noemaforge/vimanam/blob/main/scripts/benchmark-diff-refs-v23-results.json)
  - The accuracy checks [`scripts/benchmark-diff-accuracy.py`](https://github.com/noemaforge/vimanam/blob/main/scripts/benchmark-diff-accuracy.py) and [`scripts/benchmark-diff-accuracy-formats.py`](https://github.com/noemaforge/vimanam/blob/main/scripts/benchmark-diff-accuracy-formats.py), with [OpenAPI](https://github.com/noemaforge/vimanam/blob/main/scripts/benchmark-diff-accuracy-v23-results.json), [GraphQL](https://github.com/noemaforge/vimanam/blob/main/scripts/benchmark-diff-accuracy-graphql-v23-results.json) and [Protobuf](https://github.com/noemaforge/vimanam/blob/main/scripts/benchmark-diff-accuracy-protobuf-v23-results.json) results

## Reproduce all captures

```bash
# 1. Pure-Rust .proto compilation verified with empty PATH
VIMANAM="$(command -v vimanam)"
git clone --depth 15 https://github.com/open-telemetry/opentelemetry-proto.git
hyperfine --env PATH= --warmup 2 --runs 10 \
  "'$VIMANAM' opentelemetry-proto/opentelemetry/proto/collector/trace/v1/trace_service.proto -I opentelemetry-proto --detail full --include-schemas --no-report"

# 2. Full public benchmark suite, pinned revision diffs, and 4 external baselines
uv run --with tiktoken python3 scripts/benchmark-public.py \
  --baseline /path/to/vimanam-2.2.0 \
  --candidate /path/to/vimanam-2.3.0 \
  --corpus /path/to/vimanam-eval-corpus \
  --runs 10 \
  --output scripts/benchmark-v23-results.json

# 3. Serial 6-condition LLM evaluation (cold trials + warm replays; ~1 h, a few USD).
#    Build the pinned corpus first: see "Corpus" in scripts/README.md.
uv run --with tiktoken python3 scripts/eval-context-accuracy.py \
  --vimanam /path/to/vimanam-2.3.0 \
  --corpus /path/to/vimanam-eval-corpus \
  --model haiku \
  --trials 3 \
  --workers 1 \
  --output scripts/eval-context-accuracy-v23-results.json

# 4. OpenAI and Stripe diff timings against a baseline binary
python3 scripts/benchmark-diff-refs.py --binary /path/to/vimanam-2.3.0 \
  --baseline /path/to/vimanam-2.2.0 --baseline-timeout 30 --allow-different \
  --corpus /path/to/vimanam-eval-corpus --runs 5 \
  --output scripts/benchmark-diff-refs-v23-results.json

# 5. Accuracy against oasdiff, graphql-inspector and buf on real histories
python3 scripts/benchmark-diff-accuracy.py --binary /path/to/vimanam-2.3.0 \
  --corpus /path/to/vimanam-eval-corpus \
  --output scripts/benchmark-diff-accuracy-v23-results.json
python3 scripts/benchmark-diff-accuracy-formats.py graphql --binary /path/to/vimanam-2.3.0 \
  --corpus /path/to/vimanam-eval-corpus \
  --output scripts/benchmark-diff-accuracy-graphql-v23-results.json
python3 scripts/benchmark-diff-accuracy-formats.py protobuf --binary /path/to/vimanam-2.3.0 \
  --corpus /path/to/vimanam-eval-corpus \
  --output scripts/benchmark-diff-accuracy-protobuf-v23-results.json
```
