### Standalone LLM context compression (`v2.2.0`)

## Upgrade analysis: v2.2.0 vs v2.1.0

Vimanam `2.2.0` replaced external `protoc` with pure-Rust `protox 0.10`, migrated GraphQL SDL from `graphql-parser 0.4` to `apollo-parser 0.8`, migrated YAML from `serde_norway` (`unsafe-libyaml-norway`) to pure-Rust `serde-saphyr 2.2`, added `.proto` source comments, and resolved `RUSTSEC-2026-0486`.

### Protocol Buffers: 4.1x–6.3x faster with zero `protoc`

Eliminating `protoc` subprocess spawns and temporary descriptor files cuts compile-and-render latency across every public `.proto` target while running with `PATH=""`:

Across the full 13-file public Protobuf corpus (all 11 OpenTelemetry `.proto` files plus both gRPC Health versions):

- **Batch speed**: `0.774 s` (`v2.1.0`) → **`0.187 s`** (`v2.2.0`, **4.14× faster**) with **`13 / 13`** passing under `PATH=""`.
- **Neutral contract parity**: **`13 / 13`** exact `ve2_` surface match between `protoc 36.2` and `protox 0.10`.
- **Peak memory**: dropped **38–51%** on single-file runs (`12.0–12.9 MB` → `5.9–8.0 MB`) because no child `protoc` process or temporary descriptor buffer is allocated.
- **Git-ref `.proto` diff (`open-telemetry/opentelemetry-proto` @ `d31f7ac`)**: **`2.54×` faster** (`2,360 ms` → `931 ms`), **55.8% fewer CPU instructions** (`698.3M` → `308.8M`), and **34% lower peak RSS** (`12.6` → `8.3 MB`), with **100% identical JSON diff output**. On large monorepos with thousands of committed `.proto` files, the speedup grows past **100×** because `v2.2.0` lazily reads only imported Git blobs in memory instead of writing every committed `.proto` to disk.

### Protobuf documentation quality: `.proto` comments and `$ref` field metadata

Across the 13 public `.proto` files, rendered Markdown documentation grew **+106%** (`95.0 KB` → `195.8 KB`) as `.proto` comments and `Field #N` notes on singular message, enum, and `map<K, V>` fields (`189` → `295` field annotations) are now preserved while keeping neutral `ve2_`/`vc2_` IDs comment-invariant.

## Measured trade-offs and caveats

<Aside type="caution" title="Honest trade-offs in v2.2.0">
  - **Binary size**: the release binary grew from `7.24 MB` to `9.28 MB` (`+2.04 MB`) to bundle pure-Rust `protox`, Google well-known descriptors, `apollo-parser`, `serde-saphyr`, and optional Nushell/manpage generators.
  - **Large SDL & YAML wall time**: `apollo-parser`'s lossless CST adds `+12.2 ms` on GitHub's `1.2 MB` GraphQL SDL (`52.9 -> 65.2 ms`) in exchange for modern GraphQL syntax (`extend schema`, `@oneOf`) and stricter validation. Pure-Rust `serde-saphyr` adds `+13.4 ms` on Stripe's `6.3 MB` YAML (`203.4 -> 216.8 ms`) in exchange for `-20.5%` peak RAM, zero `unsafe` C code, merge-key expansion, and parsing OpenAI's official `openapi.yaml`.
  - **Mixed `protoc` `.pb` vs `v2.2.0` `.proto` diffs**: source-to-source diffs under `v2.2.0` are deterministic across machines because `protox` pins one bundled `google/protobuf/descriptor.proto`. Comparing a prebuilt `.pb` from a newer `protoc` (such as `libprotoc 36.2`) directly against a `.proto` compiled by `v2.2.0` can report differences inside `google.protobuf.descriptor.proto` if the schema imports it transitively.
</Aside>

## Reproduce these benchmarks

You can reproduce every measurement locally with `vimanam` `2.2.0` and `hyperfine`:

```bash
# 1. Stripe 7.9 MB OpenAPI JSON & 6.3 MB YAML
curl -fsSL https://raw.githubusercontent.com/stripe/openapi/master/openapi/spec3.json -o stripe.json
curl -fsSL https://raw.githubusercontent.com/stripe/openapi/master/openapi/spec3.yaml -o stripe.yaml
hyperfine --warmup 2 \
  'vimanam stripe.json --detail full --include-schemas --no-report' \
  'vimanam stripe.yaml --detail full --include-schemas --no-report'

# 2. OpenAI 1.3 MB OpenAPI YAML
curl -fsSL https://raw.githubusercontent.com/openai/openai-openapi/manual_spec/openapi.yaml -o openai.yaml
vimanam openai.yaml --operation "POST /chat/completions" --detail full --include-schemas --schema-depth 2 --no-report

# 3. GitHub 1.2 MB GraphQL SDL & 4.7 MB Introspection JSON
git clone --depth 5 https://github.com/octokit/graphql-schema.git
hyperfine --warmup 2 \
  'vimanam graphql-schema/schema.graphql --detail full --include-schemas --no-report' \
  'vimanam graphql-schema/schema.json --detail full --include-schemas --no-report'

# 4. OpenTelemetry Proto (pure Rust with empty PATH)
git clone --depth 15 https://github.com/open-telemetry/opentelemetry-proto.git
PATH="" hyperfine --warmup 2 \
  'vimanam opentelemetry-proto/opentelemetry/proto/collector/trace/v1/trace_service.proto -I opentelemetry-proto --detail full --include-schemas --no-report'
```
