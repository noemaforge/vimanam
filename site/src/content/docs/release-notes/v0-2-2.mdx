Vimanam 0.2.2, released on 2026-06-11, makes Vimanam easier to install and track. It adds a version flag, publishes to crates.io, and starts a changelog.

For more information, refer to the [0.2.2 changelog entry](https://github.com/noemaforge/vimanam/blob/main/CHANGELOG.md#022---2026-06-11).

## Version flag

<Badge text="New" variant="success" />

`--version` and `-V` print the installed version.

## Published on crates.io

<Badge text="New" variant="success" />

Release tags now publish the crate to crates.io automatically, with registry keywords and categories.

## Changelog

<Badge text="New" variant="success" />

The project now keeps a `CHANGELOG.md`, and release notes are generated from it.
