Each release has its own page that explains what changed and what you need to do when you upgrade. Start with the latest release, or with the release after the one you run today.

For more information, refer to the [full changelog](https://github.com/noemaforge/vimanam/blob/main/CHANGELOG.md).

## Read the badges

Each change on a release page has one badge, and the page lists them in this order:

- <Badge text="Breaking change" variant="danger" /> You need to change a command, a configuration, a CI setup, or library code.
- <Badge text="New" variant="success" /> A new flag, command, input format, or capability.
- <Badge text="Enhancement" variant="note" /> An existing feature works better, including fixes you might notice.
- <Badge text="Behavior change" variant="caution" /> Something works differently, and you don't need to change anything.
