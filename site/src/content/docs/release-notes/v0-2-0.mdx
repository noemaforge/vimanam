Vimanam 0.2.0, released on 2025-03-18, adds OpenAPI 3.0 support. Vimanam now reads OpenAPI 3.0 specs as well as Swagger 2.0.

For more information, refer to the [0.2.0 changelog entry](https://github.com/noemaforge/vimanam/blob/main/CHANGELOG.md#020---2025-03-18).

## OpenAPI 3.0 support

<Badge text="New" variant="success" />

Vimanam now reads the following OpenAPI 3.0 elements:

- The `openapi` version field.
- `servers`.
- `components`.
- `requestBody`.
- Security schemes.
