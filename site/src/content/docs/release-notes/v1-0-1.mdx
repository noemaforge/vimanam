Vimanam 1.0.1, released on 2026-07-07, is a small maintenance release. It was published as a GitHub release, but its crates.io publish failed, so 1.0.1 never appeared on crates.io.

For more information, refer to the [1.0.1 changelog entry](https://github.com/noemaforge/vimanam/blob/main/CHANGELOG.md#101---2026-07-07).

## Documented MSRV corrected to 1.96

<Badge text="Enhancement" variant="note" />

The documentation now gives the minimum supported Rust version as 1.96, the actual MSRV since 1.0.0. It used to say 1.85.

## Response model has its own `$ref` field

<Badge text="Behavior change" variant="caution" />

The `Response` model now has a dedicated `$ref` field instead of relying on flattened extensions. This matches the other model types that can hold a reference.
